# 항공권 예매 사이트 — 실행 & 배포 가이드

## 파일 구성
- `index.html` — 5개 페이지 구조 (전부 이 안에 섹션으로 들어있음)
- `style.css` — 모든 색/크기/레이아웃. **비주얼만 바꾸고 싶다면 이 파일만 건드리면 됩니다.**
- `data.js` — FROM 도시 목록, TO 공항 목록 (이름/좌표/국가). 목적지 추가·삭제는 여기서.
- `app.js` — 실제 동작 로직 (지도, 좌석, 예약 저장)
- `supabase-schema.sql` — 좌석 데이터를 여러 방문자가 공유하게 만드는 DB 테이블 정의

## 1단계 — 우선 내 컴퓨터에서 확인하기
아무것도 설치할 필요 없이, `index.html` 파일을 더블클릭해서 브라우저로 열면 바로 작동합니다.
(이 상태에서는 예약 데이터가 내 브라우저에만 저장됩니다 — 아직 다른 사람과 공유되지 않음)

## 2단계 — GitHub Pages로 무료 배포하기
1. github.com 에서 새 계정을 만들고, 새 저장소(repository)를 만듭니다 (예: `flight-site`), Public으로 설정.
2. 저장소 페이지에서 "Add file → Upload files"를 눌러 이 폴더의 5개 파일(index.html, style.css, data.js, app.js, README.md)을 전부 드래그해서 올리고 Commit.
3. 저장소 상단 Settings → Pages 로 이동 → Branch를 `main` / `/root`로 설정 → Save.
4. 1분 정도 기다리면 `https://내아이디.github.io/flight-site/` 주소로 사이트가 열립니다. 이 주소를 QR/링크로 공유하면 됩니다.

편집은 GitHub 웹사이트에서 파일을 열고 연필(✏️) 아이콘을 누르면 바로 코드를 고칠 수 있고, 저장하면 사이트가 자동 업데이트됩니다. 색상만 바꾸고 싶으면 `style.css` 맨 위 `:root{}` 안의 색상 코드만 바꾸면 전체 사이트에 반영됩니다.

## 3단계 — 좌석을 모든 방문자가 공유하게 만들기 (Supabase, 무료)
지금 상태로는 각자 자기 브라우저에만 예약이 저장됩니다. 여러 명이 같은 좌석표를 보게 하려면:
1. supabase.com 에서 무료 계정 생성 → New project (이름/비밀번호는 아무거나, 카드 등록 필요 없음).
2. 프로젝트가 만들어지면 왼쪽 메뉴 SQL Editor → New query → `supabase-schema.sql` 내용을 붙여넣고 Run.
3. 왼쪽 메뉴 Project Settings → API 로 이동 → **Project URL**과 **anon public key** 복사.
4. `app.js` 맨 위의
   ```js
   const SUPABASE_URL = "";
   const SUPABASE_ANON_KEY = "";
   ```
   따옴표 안에 각각 붙여넣기.
5. GitHub에 다시 업로드(또는 웹에서 바로 수정) → 이제 모든 방문자가 같은 좌석 데이터를 봅니다.

## 4단계 (선택, 나중에) — 선택한 날짜에 자동으로 이메일 보내기
이건 정적 사이트만으로는 불가능하고, "서버가 특정 날짜에 깨어나서 이메일을 보내는" 예약 작업이 필요합니다.
가장 간단한 무료 조합:
- Supabase의 **Edge Function** + **pg_cron** (매일 한 번 실행되게 예약) 으로 "오늘 날짜와 일치하는 예약이 있는지" 확인
- 이메일 발송은 **Resend** (무료 티어)의 API를 그 Edge Function 안에서 호출

이 부분은 실제로 테스트해가며 만들어야 하는 부분이라, 사이트가 먼저 잘 작동하는 걸 확인한 뒤 다음 단계로 같이 만들어도 됩니다.

## 알아두면 좋은 제한사항
- 실시간 항공편 지도는 OpenSky Network의 무료 공개 API를 씁니다. 콜사인/국가/속도는 나오지만, 실제 "경로(route)"는 무료 API로는 제공되지 않아 근사치로 표시했습니다.
- OpenSky 무료 API는 짧은 시간에 너무 여러 번 요청하면 잠시 막힐 수 있습니다 (전시 당일 트래픽이 많으면 유의).
